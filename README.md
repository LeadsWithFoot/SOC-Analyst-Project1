# SOC-Analyst-Project1

This project simulates a real-world Security Operations Center (SOC) environment using open-source tools to detect and analyze Command and Control (C2) malware activity on a compromised server.

The lab integrates network and system monitoring tools with a SIEM (Security Information and Event Management) stack to enhance detection capabilities and map alerts to the MITRE ATT&CK framework.

## Tools Used

- Suricata (Network IDS/IPS)
- Filebeat (Log shipping)
- Elasticsearch (Search and analytics engine)
- Kibana (Data visualization dashboard)

## Project Highlights

- Custom detection rules for Suricata aligned with MITRE ATT&CK techniques
- Visual dashboards to monitor and analyze alerts
- Use of Sigma rules to standardize detections across platforms
- Hands-on experience with threat detection and incident response workflows
